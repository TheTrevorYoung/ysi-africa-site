# YSI Africa image and media protocol

YSI Africa uses a visual-first website direction while protecting the distinction between documentary evidence and contextual/reference imagery.

## Evidence imagery

These assets may be presented as YSI field evidence when their provenance and captions support that use:

- `ysi-hero-real.jpg` — real YSI documentary field photograph used in the homepage hero and other institutional storytelling.
- `lumley-field-2026-04-23.webp` — optimized documentary photograph from Lumley Beach field cleanup work, dated 23 April 2026. It is contextual field evidence and is not presented as Phase 0 measurement data.
- `favicon.svg` — browser/site interface icon.

## Context/reference imagery

The website may use relevant publicly available photographs, satellite imagery or embeddable video as **interim visual context and creative reference** when YSI does not yet have the required local asset. Such media must:

1. be clearly distinguishable from YSI field evidence;
2. never imply that YSI conducted the activity shown;
3. have a traceable source and reuse/embedding basis;
4. use accurate captions and attribution where required;
5. be replaced by commissioned/local YSI media when an appropriate asset becomes available.

## Direction

The site should feel alive, place-based and African: real environments, field activity, people, materials and systems should carry the story visually. Empty decorative blocks and generic sustainability imagery should be avoided. Where a contextual public asset is used, it also serves as a creative brief for later commissioned Sierra Leone photography/video.
