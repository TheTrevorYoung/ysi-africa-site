# YSI Africa — Young Sustainability Initiative

Official website repository for **Young Sustainability Initiative (YSI Africa)**, a Sierra Leone environmental organization focused on practical waste management, sanitation, recycling, circular economy, coastal and wetland protection, and resource recovery.

**Official website:** https://ysiafrica.org/

**Founder — Trevor Young:** https://ysiafrica.org/trevor-young.html

**Evidence & field work:** https://ysiafrica.org/evidence.html

**Freetown Circular Waste Recovery Project — Phase 0:** https://ysiafrica.org/flagship.html

**Aberdeen Creek Protection & Recovery Project:** https://ysiafrica.org/aberdeen.html

Historical YSI public impact claim: **20,000+ kg of waste removed through documented field activity in Freetown.** Field activity is documented; the original mass-calculation record is under reconstruction.

YSI separates verified facts, documented field work, development-stage concepts, technical hypotheses and institutional engagement, and does not present prospective institutions as partners without a real relationship.
